# Chronicle consumer

`mountChronicle` accepts an ordered, complete `History` and a host-owned `ReplayBinding`. `replace` must atomically replace the isolated replay presentation from the supplied snapshot, including backward seeks; it must not deliver historical beats to live feeds. `clear` removes the replay, and `dispose` restores or reveals the live presentation without touching its movement, chat or state. The close callback receives any cleanup error so the host can restore live presentation or report the failure. Host integration and export wiring belong to main. Invalid histories or unavailable scene revisions show an unavailable state rather than a stale success.

`bench.html` is a local SIMULATED demonstration. Its home and market construction revisions are explicit fixture facts; no qualification stage is treated as proof of construction. The fixed generated castle, streets, other civic sites and other homes are scenery, not a historical reconstruction. It makes no endpoint or persistent record.

Main still needs a durable, versioned history contract with ordering, timestamps, provenance, redaction and complete world snapshots or deterministic reconstruction; authoritative bindings for home geometry, civic places, castle and streets; and a live/replay isolation and restoration port. Current `GrowthSceneFrame` is a bounded current projection, not that history.

The local bench swaps recorded meshes in a separate scene, but the borrowed stage's cached sun shadows and light-field blockers still describe its original geometry. A production replay binding needs a stage-owned way to replace geometry and refresh both shadow casters and lighting blockers together on every seek and restoration. Judge the simulated bench's resulting lighting in the first, latest, and market captures; it is not evidence that historical lighting is reconstructed.

To capture the local bench, run `node apps/web/src/chronicle/capture.mjs --view first --size desktop` from the workspace root. Choose one view (`first`, `latest`, or `market`) and one size (`desktop` or `phone`) per invocation. The still runner builds a private optimized preview before acquiring the shared slot and takes one still. For interactive seek and accessibility checks use `node apps/web/src/chronicle/watch-check.mjs --check desktop` (or `phone`); use `--record` for the single 30-second clip. Each invocation selects a free permitted capture port, holds the shared capture lock for one capture or check, waits safely if the host is full, and uses SwiftShader. This bench is not a production route.
