# Soul presentation

`createSoulSceneHost` accepts `shipArrivals` on each update: a bounded snapshot of recent arrival epochs actually witnessed by the kingdom. Main owns that event history and must supply it as arrivals happen; the host never invents arrivals. Omit the field to use the binding's static `config.shipArrivals`, useful for rehearsals. Equal snapshots reuse the sampler. At a harbour, each newly witnessed eligible arrival can ring once, including arrivals within twelve seconds of one another. Mounts, clock seeks and muted or locked audio consume the current arrival without a delayed attack. The host uses the caller's audio context without owning it.

`createSoulPresentation(scene, { topology, chimney? })` owns only its added objects. Call `update(frame, seconds)` with a `SoulFrame` from `createSoulSampler` each frame; call `dispose()` on teardown. The topology must describe actual connected street and lamps in scene coordinates. It rejects more than 64 lamps; split a larger settlement into districts. weather particles cover the district centred on the supplied routes. The optional chimney is the real bakery mouth; no chimney means no smoke. Keepers are civic workers, never citizens, and this adapter creates no presence lights.

`createSoulWeatherSurfaces({ roofs, snow, puddles })` applies the same wetting and snow visibility as the review to caller-supplied roof materials and geometry. Call `update(frame)` and `dispose()` to restore their initial properties. Supply distinct roof materials if other surfaces should not be darkened.

The `/-/soul` review rasterizes the actual Hearth blueprints, including ordered air cuts, through the existing voxel mesher. It reuses three families and merges their exposed surfaces by palette; snow follows exposed upward roof faces rather than solid-box approximations. A single owned module worker prepares the families serially and transfers their buffers; the UI remains responsive during meshing, and unmount settles pending work and terminates the worker. The review shows its opening state until a meaningful frame, with time and sound controls disabled until then. The main kingdom keeps its existing worker pipeline. The compact default topology remains a simulated district. `?seed=42&date=2026-06-20&hour=6&biome=coastal&weather=natural` fixes a capture; omit hour for a live clock. `weather=clear|rain|snow` is a review override, and `view=stream` hides controls. `window.__chatdomReady` indicates the first rendered frame, `window.__soulFrame` exposes the current sample, and `window.__soulSetHour(hour)` fixes the review clock. The internal `window.__soulStats` records draw calls, triangles, points and allocated geometry/texture counts for evidence, not GPU timing. Audio requires the user's sound button; it shares the kingdom audio host and uses the stream mix in stream view.
