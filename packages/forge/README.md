# Forge grammar core

Words propose a **HousePartPlan**, never voxels, code, materials, identity, location or approval. The first consumer
supports the sleeping-dragon chimney, crescent lantern and owl vane. The strict union grows with reviewed authored
families; unsupported wishes fail without fallback geometry. `planLocalForge` is a deliberately finite, labelled
local language, not a connected Codex run or moderation gate.

`forgeStyleKit` resolves Hearth, Tide or Grove native kits. `assembleForge` resolves registered motifs and constructs
stack, saddle, bracket or post with integer build cells. It never modifies the host. Same words produce different
geometry and materials in the three kits. `findForgeSockets` derives stepped roof support and clear front-wall
anchors from actual retained occupancy. Sockets bind to the whole host fingerprint, not a convenient bounding box.
`checkForge` rechecks that socket, canonical assembly, bounds, collision, window clearance, connected geometry,
material count and occupied/source budgets. Worker meshing adds the actual triangle check before presentation.
These are craft/fit checks, **not beauty or safety approval**; looked-at authored silhouettes and external judges
are separate requirements. The mesh is never cropped or thinned to meet a budget.

The style kit resolver accepts an explicit saved revision. Revision one remains the default and retains its
existing geometry, including version-two plans. Revision two is an explicit content-review candidate with a
framed lantern chamber and a clearer sleeping fox. It is not yet activated for new authority work. Saved pieces
must use their recorded kit revision; an unknown revision fails closed. The approval binds the exact kit as well
as the draft and home. Core scene/growth integration needs and promotion checks are in
`work/lanes/forge-wish/SEAMS.md`.

Attachments are exact geometry beside the shaped source. They never go through `BuildDraft.insertBlueprint`
(which replaces a whole box) or architectural shaping (which would reinterpret a sculpture). Local placement
receipts are a separate versioned sidecar. The browser reassembles and checks them on reload; a changed house
invalidates their sockets. Main must extend source-aware placement reconciliation before live edit/publish. Masonry stacks are crowned directly; roof saddles serve homes without a stack. Lanterns use a clear in-lot wall bracket or roof perch, never an overhang into the street.

The browser demonstrator spends no coal and mints no public item/provenance. It labels its local grammar and
unconnected Codex/judges. Only after actual assembly, check and worker mesh does a 21-second presentation run;
arrival rechecks the host and installs the retained piece. The public refusal projection contains only a generic
variant, with one beat per ten minutes. No prompt or maker goes into its effect/audio interface.

Live service integration still needs authenticated ownership, live/anvil/earned-coal reservation, external input
and result gates, the Codex plan call, durable idempotent publication and provenance. None is simulated as approval.
Spec 09 retains architectural piece-family ownership. Specs 17–18 hand rich ritual/audio/refusal presentation to
the team. The prototype lessons are in `work/references/prototypes.md`; all implementation here is original.
