# Kingdom soul audio

After the listener's gesture unlocks the kingdom audio engine, pass `kingdomAudioHost(audio).context` and `.destination` to `createSoulAudio`. Call `update({ frame, biome, listener, profile, presence })` on every frame. The frame is the world `SoulFrame`; listener coordinates and right vector are in kingdom metres. Presence is the number of people actually present, not keepers. `walk` is the normal profile; `stream` lowers the mix and carves a pocket for speech. Call `duck({ depthDb, seconds })` for a witnessed moment or Voice line (defaults to 6 dB for 2 seconds), use `setMuted` and `dispose` for the listener lifecycle. Call `cue('arrival')` only for an actual arrival. No context is created, resumed, or closed here.

This is the **replacement** for the Genesis land ambience during kingdom life: do not run both at once. It reuses Genesis's synthesised bird, harbour and water-drop voices and noise kit. Its own music, weather and place sounds live on the host master. A smith's work is positioned from the keeper; no harbour bell is fabricated. Music uses related biome modes, hour-sensitive register and phrasing, with strings, woodwind and choir entering as presence increases. Snow quiets the land; wind, rain, fog and temperature affect its layers. Calls and music have a strict shared source/voice ceiling in addition to three beds. Missing frames fade the graph; time jumps skip missed events.

## Listen and measure

From the repo root run `node packages/audio/src/soul/bench/listen.mjs coastal-6-walk` for one case (the argument defaults to that case). Each invocation builds a standalone bench before taking the capture lock, waits up to ten minutes without starting a browser or server, renders one short clip or check, writes its result in `/tmp/chatdom-soul-audio`, then closes its browser and server and releases the lock. Run the four biomes at 6, 12, 18 and 23 in `walk`, add each biome at `18-stream`, and run `meadow-6-hamlet`, `lifecycle`, `stall` and `duck`. Run `node packages/audio/src/soul/bench/listen.mjs --finalize` to validate those results and write `measurements.json`. Listen on headphones and speakers at the same volume, including the stream files under speech. The script asserts signal, peak, source budget, stream attenuation, mute/resume, seek and the stalled-frame fade. Run `node packages/audio/src/soul/bench/analyze.mjs` afterward for FFmpeg integrated LUFS, true peaks and spectrograms in the same directory. `renderSoulAudio` is browser-callable and uses the live graph with an OfflineAudioContext. It can also render changing or missing frames to inspect transitions.

Noise beds are procedural and their playback rates drift independently; they are not field recordings. The rendered captures are evidence for review, not a substitute for a real device and stream-voice mix check.
